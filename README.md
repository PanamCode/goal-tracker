# Цель — Трекер целей

Красивый и современный трекер целей с градиентами, 3D-эффектами и плавными анимациями.

## Особенности

- Красивый тёмный интерфейс с живыми градиентами
- 3D-наклон карточек при наведении
- Плавные анимации появления
- Кольцо прогресса с градиентом
- Конфетти при выполнении цели
- Фильтры: Все / В процессе / Готово
- Приоритеты целей
- Сохранение в `localStorage`
- Полностью адаптивный дизайн

## Как запустить

Просто открой файл `index.html` в браузере.

Или через Live Server / любой локальный сервер:

```bash
npx serve .
```
